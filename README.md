# 🚀 Shri Vishwkarma Enterprises – Business Website

A production-ready full-stack business website built for **Shri Vishwkarma Enterprises**.  
The platform includes a lead capture system, admin dashboard (mini CRM), WhatsApp integration, and a responsive UI.

---

## 🌐 Live Links

- 🔗 Frontend: https://aluminium-enterprises-olive.vercel.app  
- 🔗 Backend API: https://sve-backend-afhs.onrender.com  

---

## 🛠 Tech Stack

### Frontend
- React (Vite)
- Tailwind CSS
- React Router
- Axios
- React Icons

### Backend
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- Helmet (Security)
- Morgan (Logging)
- Express Rate Limit

### Deployment
- Frontend → Vercel
- Backend → Render
- Database → MongoDB Atlas

---

## ✨ Features

### ✅ User Side
- Responsive landing page
- WhatsApp integration
- Direct Call buttons
- Email integration
- Lead submission form
- Smooth animations
- Floating WhatsApp chat bubble

### ✅ Admin Dashboard
- View all leads
- Update lead status (New / Contacted / Closed)
- Delete leads
- Lead statistics (Total / New / Contacted / Closed)
- Mobile responsive admin panel
